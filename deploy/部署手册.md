# self-agent 部署手册（M3-8）

## 形态一：开发机直跑（当前实测口径）

```bash
# 0. 基础设施（Postgres+Redis 复用 Aegra 的 compose）
cd vendor/aegra && docker compose up -d postgres redis && cd ../..

# 1. Aegra（协议端点，:2027）
DATABASE_URL=postgresql://postgres:postgres@localhost:5432/aegra AEGRA_CONFIG=aegra.json \
  .venv/bin/python -m uvicorn aegra_api.main:app --port 2027
# 可观测（可选）：前面加 OTEL_TARGETS=LANGFUSE LANGFUSE_BASE_URL=http://localhost:3001 \
#   LANGFUSE_PUBLIC_KEY=... LANGFUSE_SECRET_KEY=...

# 2. 网关（多渠道入口+审批桥+Playbook+管理台，:8400）
DATABASE_URL=postgresql://postgres:postgres@localhost:5432/aegra \
  APPROVAL_ADMIN_KEY=<审批服务管理密钥> \
  .venv/bin/python -m uvicorn self_agent.gateway.app:app --port 8400 --app-dir src

# 3. 前端（:3000）
cd webui && pnpm dev

# 4.（无人机业务侧，另一项目）MCP 11 域 + 审批服务 8205 照其手册启动

# P1 沙箱（可选）：execute 进隔离容器（无网络、资源限额、非 root）
docker build -t self-agent-sandbox deploy/sandbox/
# 起 Aegra 时加 SANDBOX_MODE=docker
```

## 形态二：容器化整栈（生产）

```bash
cd deploy
cat > .env <<'EOF'
POSTGRES_PASSWORD=<强密码>
LLM_API_KEY=<OpenAI 兼容端点密钥>
LLM_BASE_URL=<端点，如 token-plan compatible-mode 地址>
UAV_MCP_API_KEY=<MCP 服务密钥>
APPROVAL_BASE=http://<审批服务>:8205
APPROVAL_ADMIN_KEY=<审批管理密钥>
PUBLIC_AEGRA_URL=http://<外部可达主机>:2027
PUBLIC_GATEWAY_URL=http://<外部可达主机>:8400
EOF
docker compose up -d --build
```

服务清单：postgres(pgvector) / redis / aegra(:2027) / gateway(:8400) / webui(:3000)。
MCP 11 域与审批服务在无人机项目侧部署，经 `projects/<项目>/mcp_config.json`（Nacos
同步桥可自动维护）接入。Langfuse 栈独立部署（vendor/langfuse，端口 override
见其 docker-compose.override.yml），经 OTEL_TARGETS=LANGFUSE 三件套接通。

## 验证清单

| 检查 | 命令 | 预期 |
|---|---|---|
| Aegra 健康 | `curl :2027/health` | database/checkpointer/store 三项 connected |
| 网关健康 | `curl :8400/healthz` | ok |
| 管理台 | 浏览器 `:8400/admin` | 技能/知识库/审批/模板/文件五页 |
| 对话 | 浏览器 `:3000` | 发问得答，工作台面板可见 |
| 人在环 | 发"派机"类指令 | 审批卡片；同意后双层桥接直至执行 |
| 回归 | `python poc/run_eval_sample.py` | 抽样命中 ≥ 基线 |

## 运维要点

- **密钥**：全部经环境变量注入；.env 不入库；审计/trace 中不落密钥；
- **持久化**：Postgres 卷 `pg_data`（会话/审计/技能/知识库/模板全在库），
  工作区卷 `workspace`（交付物）；备份这两个卷即可；
- **重启恢复**：进行中 interrupt 与会话状态在 Postgres，重启后 resume 可续（M1-8 实测）；
- **升级**：改依赖必须过评测回归（uv.lock 锁定矩阵）；技能更新自动回 pending 重审；
- **已知待办**：企微适配器待凭据；EMBEDDING_* 配好后知识库 `reindex` 升向量检索。
