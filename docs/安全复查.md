## 3. 执行与注入面

| 面 | 控制 | 残余风险与说明 |
|---|---|---|
| 技能供应链 | 静态扫描（9+3 类模式）+ 默认 pending 人工审核 + 更新/回滚强制重审 | 扫描是启发式初筛，审核人是放行关 |
| 技能脚本执行 | P0 受限目录+受限 PATH+超时；P1 Docker（无网络/1G/1CPU/非 root/宿主 FS 不可见，四项实测） | P1 工作区仍全会话共享（路线图：per-session） |
| 高危工具 | interrupt（框架层）+ confirm_token（服务端唯一签发、一次性、TTL）双层；紧急白名单直通 | 桥接批准链留痕（审批人 X-User-Id） |
| 平台数据注入 | 评测 #71 反向用例（告警内容诱导急停/返航）通过 | MCP 返回内容仍属不可信文本，靠提示词纪律+白名单兜底 |
| Web 面 | 管理台无鉴权（当前默认本机） | ⚠️ 对外部署必须前置反代鉴权——已写入部署手册待办 |
| 审批防重放 | pending 才可决策（DB 状态机）+ 审批服务侧 409/410 | ✅ 实测 |
