# 功能需求说明书（FRD）

> 版本：v1.0 · 2026-08-13
> 对应《技术方案》v0.5 需求编号 R1~R19。每条需求含描述、验收标准、优先级与里程碑。
> 优先级：P0 = 核心不可缺；P1 = 重要；P2 = 增强。

---

## 1. 智能体核心

### R1 多智能体编排（P0，M0/M1）

**描述**：Lead Agent 将用户目标拆解为子任务，经 `task` 工具派发给专家子代理并行执行；子代理上下文隔离，完成后仅回传结论。子代理按「专家岗位」预配置：general-purpose、uav-ops（巡检/飞行）、research（网页研究）、doc-writer（交付物）、data-analyst（数据分析），每个岗位限定工具集与模型档位。子代理定义存 DB 配置化，改配置不改代码。

**验收**：
- 一句复合指令（含飞行作业 + 数据分析两类子任务）触发 ≥2 个子代理并行；
- 子代理只能调用其受限工具集内的工具（越权调用被拒并记审计）；
- 并行派单场景在评测集抽测中无工具调用格式错误。

### R2 任务规划与进度（P0，M1）

**描述**：Agent 对多步任务生成显式 todo 计划并随执行更新状态；计划实时推送前端渲染。

**验收**：≥3 步的任务自动产生 todo；前端计划面板实时反映每项 pending/in_progress/done；中途改需求时计划相应更新。

### R6 跨会话记忆（P1，M1）

**描述**：`/memories` 路径持久化用户偏好与项目上下文（Postgres Store），新会话自动可见；AGENTS.md 式长期记忆随 agent 加载。

**验收**：会话 A 中声明的偏好（如报告格式要求）在新会话 B 中被自动遵循；记忆内容可查看。

### R8 模型路由（P0，M0 验证 / M1 策略）

**描述**：不同子代理/任务档位使用不同 LLM。接入 DashScope OpenAI 兼容模式（qwen3-max / qwen-flash），保留 Claude 切换能力。强档：Lead、doc-writer；便宜档：research、data-analyst。

**验收**：M0 用评测集 10 条抽测 Qwen 工具调用达标（含并行派单）；不达标时混合路由（Lead 切 Claude）可一行配置切换；各档位实际路由结果可在 trace 中核实。

### R9 长任务与断点恢复（P0，M1）

**描述**：分钟~小时级任务后台执行；每步状态落 Postgres checkpointer；服务进程重启后，后台 run worker 扫描未完成 run 并从断点续跑；完成/需确认时经消息通道回推。

**验收**：任务执行中 kill 服务进程 → 重启 → run 从断点自动续跑至完成；全程用户无需重新发起。

## 2. 工具与集成

### R3 MCP 资产集成（P0，M0/M1）

**描述**：接入现有 11 个无人机 MCP 域（streamable-HTTP + `X-API-Key`）；MCP 配置由 Nacos 同步桥动态生成并热更新（IP 漂移自愈、不重启）；工具发现失败重试而非缓存跳过；run 前 healthz 快检，失败域工具本轮不挂载并在系统提示中声明。

**验收**：11 域工具全部可被正确调用；修改 `MCP_SERVICE_IP` 后不重启网关即恢复；76 条评测集全量命中率 ≥ DeerFlow 现状基线。

### R13 浏览器操作（P1，M3）

**描述**：接入 Playwright MCP（stdio 或 streamable HTTP），research 子代理可浏览网页、抓取公开数据。

**验收**：「查询某型号无人机的公开参数并汇总」任务经浏览器完成并产出结构化结果。

### R19 用户级连接器授权（P2，M3 起步）

**描述**：用户在管理页自助 OAuth 连接个人邮箱/日历等外部服务；凭据加密存 `user_credential` 表；MCP 配置生成器按 run 发起人注入对应凭据。首期支持 2~3 个高频连接器。

**验收**：用户 A 连接邮箱后可让 agent 代发邮件；用户 B 未连接则该工具不可见；A 的凭据对 B 不可见；断开连接立即生效。

## 3. 交付物与技能

### R4 交付物生成（P0，M2）

**描述**：自写文档四技能（PPT / Word / Excel / PDF，python-pptx / python-docx / openpyxl / reportlab），模板对齐无人机业务报告样式；技能脚本在沙箱内 `execute` 执行；产物落会话工作区可下载。

**验收**：「出 A 片区巡检周报 PPT」产出可打开、格式正确、数据来自真实作业结果的 PPT 文件；四种格式各有 ≥1 条交付物评测用例通过。

### R15 技能管理（P0，M2 MVP / M3 完善）

**描述**：技能全生命周期管理，对齐 Agent Skills 开放标准：
- 导入：本地上传 zip、GitHub 地址（支持 `@tag`/`@sha` 锁定、整仓扫描）、任意外部 URL、内置精选源；
- 安全流水线（必经）：结构校验 → 静态扫描（危险命令/外联/注入模式）→ 默认 pending 人工审核 → 沙箱执行兜底；
- 管理：列表/启停/更新（检查远端 ref）/版本回滚/作用域（global/tenant/user）；全程审计；
- 装配：会话开始按「发起人可见且 enabled」集合物化技能目录，新会话即时生效。

**验收**：从 GitHub URL 导入社区技能 → 审核通过 → 新会话可用全链路 ≤5 分钟；含危险命令的技能包被扫描标记；禁用技能后新会话不再加载；pin 锁定的技能不被自动更新。

### R16 知识库 / RAG（P1，M2）

**描述**：上传 PDF/Word/Markdown 文档 → 解析切分 → pgvector 入库；`search_knowledge` 工具挂 Lead 与相关子代理；管理页支持文档列表/删除/重建索引；作用域同技能三级。

**验收**：上传《巡检规范》后，问答与作业规划中正确引用其条款（抽测 5 问 ≥4 中）；删除文档后不再被检索到。

## 4. 安全与治理

### R5 人在环（P0，M0 interrupt / M2 卡片闭环）

**描述**：双层机制——① 框架层 `interrupt_on` 拦截高危工具，暂停并持久化，渲染确认卡片；② 工具内 confirm_token 最后防线（审批服务 8205 签发，一次性、动作绑定、10 分钟 TTL）。紧急白名单动作跳过 interrupt，白名单校验保留在服务端。

**验收**：`dispatch_drone` 等 🔒 工具未经确认不执行；批准后凭 token 执行、重放被拒；伪造 token 被拒；紧急白名单动作直通；企微/钉钉/Web 三端确认卡片均可完成批准。

### R11 治理与审计（P0，全程）

**描述**：延续三关鉴权（接入关网关鉴权 / 操作关审计中间件 / 回源关 MCP 服务端校验）；audit_mw 记录 who/tool/args 摘要/结果/耗时；身份链按 docs/09 阶段 1 声明式注入，追责到人。

**验收**：任一高危操作可从审计表还原「谁在何时经哪个会话触发」；审计记录与 Langfuse trace 经 run_id 关联。

## 5. 入口与体验

### R7 多渠道入口（P0，M1 Web / M2 企微钉钉）

**描述**：Web（SSE 流式）+ 企业微信 + 钉钉（webhook 收发，验签，会话映射 thread_id；流式降级为分段消息；确认卡片用平台交互卡片）。

**验收**：三端各完成一次含人在环确认的完整任务；同一用户跨端身份统一。

### R10 工作台前端（P0，M1 对话 / M2 面板）

**描述**：agent-chat-ui 基座二开：对话流、todo 计划面板、子代理活动流、工作区文件浏览/下载、确认卡片、技能管理页、知识库管理页。开发期连 `langgraph dev`，生产连自建协议端点（或 Aegra）。

**验收**：一个任务的计划、子代理活动、产物文件在前端全部可见可下载。

### R12 评测体系（P0，M1 回归 / M3 扩充）

**描述**：复用 76 条评测集作回归基线；新增交付物类评测（文档生成正确性）；依赖升级必须过全量回归。

**验收**：CI 或脚本一键跑全量评测并输出命中率报告；两版依赖矩阵对比报告可产出。

### R14 定时任务（P2，M3）

**描述**：cron 表达式触发预设任务（与 R18 Playbook 共用存储），结果经消息通道回推。

**验收**：配置「每周一 9:00 巡检周报」后连续两周自动产出并推送。

### R17 线上可观测（P1，M1）

**描述**：自托管 Langfuse，LangGraph callback 集成；run 级 trace（工具调用链、token/成本、时延）；成本看板。

**验收**：任一 run 可在 Langfuse 中查到完整调用树与 token 成本；按用户/日聚合成本可查。

### R18 任务模板 / Playbook（P2，M3）

**描述**：高频任务定义为参数化模板（预置 prompt + 参数槽 + 默认技能/子代理集合）；模板库页一键发起；可挂 cron。

**验收**：「周报巡检」模板带参数（片区）发起，产出与手工口述等效；模板可编辑、复制、停用。
