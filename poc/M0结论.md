## 踩坑记录

1. **langgraph dev 必须加 `--no-reload`**：dev 持久化每 10s 写 `.langgraph_api/`
   触发 watchfiles 无限热重载，端口永远绑不上（症状：日志正常但 connection timeout）。
2. **langgraph.json 的 graph 必须用模块路径**（`self_agent.graph:make_graph`），
   文件路径加载不支持包内相对导入。
3. HITL 决策类型是 `approve/edit/reject/respond`（不是 accept）。
4. token plan 的 key 只对 token-plan 端点有效，打标准 DashScope 端点返回 401。
5. agent-chat-ui 的 pnpm 版本严格检查：`npm_config_package_manager_strict=false`。
