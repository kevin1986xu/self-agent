# self-agent · 自研智能体框架

对标 WorkBuddy 的「数字同事」框架：任务拆解 → 多子代理并行 → 调用 MCP 工具 / 技能 → 产出交付物（报告/PPT/表格），支持 Web / 企业微信 / 钉钉入口与人在环审批。

内核采用 **deepagents（LangChain）+ LangGraph**，自研集中在五处：消息网关、MCP 配置生成器（Nacos 动态发现）、审计/模型路由中间件、技能管理服务、前端二开。完整复用既有无人机智能体的 MCP 资产（11 业务域 / 审批服务 / Nacos 桥 / 业务技能 / 76 条评测集）。
